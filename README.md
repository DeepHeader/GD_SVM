## 기획 의도

DeepHeader는 딥러닝의 주요 개념을 함께 공부하고, 배운 내용을 비전공자에게도 쉽게 설명할 수 있는 교안을 만드는 것을 목표로 시작했습니다. 이 저장소에는 **경사하강법**과 **SVM**을 직접 실험하며 배울 수 있는 웹 교안을 담았습니다.

## 제작 방법

각 수업은 **질문 → 그림으로 이해하기 → 수식 직접 조작하기** 순서로 구성했습니다.

- **경사하강법**은 “안개 낀 산에서 어느 쪽으로 한 걸음 내디딜까?”라는 질문으로 시작합니다. 발밑의 경사와 걸음의 크기를 그림으로 이해한 뒤, 수식 속 학습률 η를 움직여 한 걸음이 얼마나 달라지는지 확인합니다. 이어서 같은 지형에서 경사하강법·모멘텀·Adam의 이동 경로를 비교합니다.
- **SVM**은 “두 무리를 가르는 선이 여러 개라면 어떤 선을 고를까?”라는 질문으로 시작합니다. 먼저 두 무리 사이에 선을 그어 보고, 수식의 값을 바꾸며 경계선과 가장 가까운 점 사이의 간격이 어떻게 달라지는지 살펴봅니다.
