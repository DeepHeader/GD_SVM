## 기획 의도

DeepHeader는 딥러닝과 머신러닝의 주요 개념을 함께 공부하고, 배운 내용을 비전공자도 직관적으로 이해할 수 있는 교안으로 전달하는 것을 목표로 합니다. 이 프로젝트는 경사하강법과 SVM의 원리를 단순한 수식 암기가 아닌 직접 조작과 실험을 통해 이해하도록 설계했습니다.

## 제작 방법

각 실험실은 **쉬운 비유 → 개념 이해 → 움직임 관찰 → 직접 실험 → 이해도 확인** 순서로 구성했습니다. 개념 슬라이드와 시각화를 통해 원리를 익히고, 수식 속 기호를 마우스로 드래그하여 값의 변화가 실제 결과에 어떻게 반영되는지 확인할 수 있습니다.

## 주요 기능

### 01. 경사하강법 (Gradient Descent)

- 안개 낀 산을 내려가는 비유를 활용한 손실 함수, 기울기, 학습률 개념 학습
- 학습률과 시작 위치에 따른 수렴, 진동, 발산 과정 및 손실 그래프 관찰
- 3D 지형에서 기본 경사하강법, 모멘텀, Adam의 이동 경로 비교
- 로컬 미니멈, 안장점, 좁은 골짜기 실험 및 최적화 파라미터 조절

### 02. 서포트 벡터 머신 (SVM)

- 두 그룹 사이에 가장 넓은 길을 만드는 비유를 활용한 결정 경계, 마진, 서포트 벡터 개념 학습
- 데이터 포인트 추가·이동·삭제와 선형 및 RBF 커널의 분류 결과 비교
- C와 γ의 변화에 따른 결정 경계, 마진 위반 및 학습 데이터 정답률 관찰
- 동심원 데이터를 새로운 높이 좌표로 변환하는 2D → 3D 차원 확장 실험

두 실험실 모두 마지막에 이해도 확인 퀴즈를 제공합니다.
